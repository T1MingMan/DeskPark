# 拖拉机：本桌规则与实现边界

## 规则来源与取舍

主要依据 [John McLeod / Pagat: Tractor](https://www.pagat.com/kt5/tractor.html)，在本次工作中用 HTTPS 直接读取全文（网页显示最后更新 2026-11-01）。该来源明确说明地区规则有差异，不存在这里所声称的统一全国标准。来源要点：两副108张、四人固定搭档、发牌期间亮主、同门 top-set 甩牌、对家也能指出甩牌失败、退回牌每张转10分、强制领可压的牌组且指出者须压、混合主杀按对子/单张比较。

本桌是**明确的双副牌家规组合**，不是 Pagat 全文照搬，也不声称为竞技协会规则。

| 项目      | 本桌确定规则                                                                                                                | 与来源/其他常见规则的区别                                                                                    |
| --------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 发牌      | 系统每1100ms给每座一张，共25次；每位在线非托管真人遇新合法亮主机会时冻结全部电脑/系统，确认后继续；发完留2400ms最后亮主窗口 | 现实逐座摸牌以四人一轮合并为一次服务端 tick；不是先发完再做客户端动画                                        |
| 抢亮/反主 | 任意座位可立即亮自己已有的单级牌、同花级对、小王对、大王对；强度1/2/3/4，只许更强；允许自保升级                             | Pagat 限制自己直接反自己；本桌允许；王对无主仍保留级牌为主                                                   |
| 默认主/庄 | 无人亮默认黑桃；首局首位亮主者坐庄，无人亮0号坐庄；之后得分轮庄                                                             | Pagat 无人亮时翻底定主、首局重发，首局最终定主者坐庄；本桌保留原来明示家规                                   |
| 主牌      | 王、级牌、主花色；同点副级不同花不成对；无主时级牌仍为主                                                                    | 跳过级牌的自然连对，主A可接副级、主级、王；同大先出胜                                                        |
| 甩牌      | 同一有效门任意混合牌组，按最长连对优先、同长低点优先确定拆分，再对子、单张                                                  | 不把非连续对子错误认成整条拖拉机；不跨门甩；不提供跨门/三副牌等其他玩法                                      |
| 失败判定  | 服务端用完整状态检查其余三家（含对家）的**同门**单张、对子或同长拖拉机，主杀不使甩牌失败                                    | 不以机器人猜测代替；客户端看不到反制者的具体牌                                                               |
| 失败回退  | 在可被压的成分中选最少张数，再选最小点数，剩余牌原样退手                                                                    | 同点按稳定牌ID打破选择歧义；可压牌者按出牌方向最近座位选择                                                   |
| 失败罚分  | 每退回1张转10分；庄家甩错给闲家分加罚分，闲家甩错减罚分，可负数                                                             | 不是“不罚分”变种；不是每次固定10分，也不是对所有尝试牌都罚                                                   |
| 强制压    | 已确定的可压牌者，轮到时必须同门压过强制领出的组                                                                            | 公布座位和被压成分，不公布实际反制牌/全手                                                                    |
| 跟牌      | 先跟足有效门；缺门跟完再任意垫足。按领牌拖拉机长度从长到短尽量跟最长片段，再跟足领牌对子数                                  | 对应 `obligation` 词典序轮廓；等长选择会穷举而非贪心导致错误。甩全单张不强迫跟对子                           |
| 主杀/胜负 | 完全缺门才可能整手主杀，须完整覆盖领牌的拖拉机、对子、单张结构；不要求额外单张互不成对                                      | 多家主杀比较最大成分：最长拖拉机最大点、否则最大对子点、否则最大单张点；同大先出胜。不是“手里最高王最大就赢” |
| 扣底      | 最大成分单张×2、对子×4、N连对×2^(N+1)                                                                                       | 混合甩按最大成分，不按总张数；Pagat 采用多张领牌总张数×2，本桌不同                                           |
| 升级      | 闲家≤0庄升3；1–39庄升2；40–79庄升1；80–119闲家上台不升；120起每40升1                                                        | 无必打级、无反底/炒底、无钩子                                                                                |
| 连续局    | 默认 `rounds:0`，每局结算后四人准备可继续，过A循环至2，升级余量保留                                                         | 来源过A结束；为满足“不限局”明确改成循环。有限场可配置1/3/5等，封顶A后到所选局数结束                          |

## 信息边界

`drawPile`、`rng`、其他三家的手牌不进入任何 `TractorView`。旁观者无手牌、发牌和进行中无底牌。亮主牌、甩错尝试牌与回退成分、罚分和指出座位属于公开事实。除庄家自己的底牌外，底牌只在本局结算公开。机器人只接受同样的 view；纯规则模块没有 DOM、Node、网络或时钟调用。

## 客户端与设备

主站和独立 `/legacy-tractor/` 使用同一个 `tractor` GameDefinition，旧入口仍是本地一人三电脑，不擅自扩展联机。主站继续支持服务端权威联机。真人提示按钮及独立会话 hint API 已删除，测试通过可见手牌点击，不保留隐藏的人类提示入口。

布局用正常文档流/独立手牌目标替换主站旧版绝对定位叠放；小屏可纵向滚动到完整手牌，不横向裁掉牌。桌面和平板可完整展现；844×390 手机扣33张时允许桌内自然滚动，不声称所有信息同时装进一屏。独立旧版不依赖 flex gap、CSS min/max/clamp、ResizeObserver、Worker、PointerEvent 或 structuredClone。ES5语法检查和删API后的 Chromium/WebKit 测试不等同真实 iOS12.5.8 Safari 验证，仍需用户实机确认性能与触控。

## 验证入口

### 原版主站单机 / 联机改版（2026-11-06）

入口：`http://<局域网IP>:8787/#/play/tractor`。单机和房间联机共用 React 棋桌与 `Table` 调度器，联机权威状态仍在服务端，不是客户端动画暂停。

- 共享发牌节拍改为1100ms；`declarationChoices` 从当前座位已收到的牌生成黑桃、红桃、梅花、方块、无主五项，均与 `validate` 的同一 `bidStrength` 判定一致。亮主固定面板、主花色/级牌/亮主者、相对四方座位、轮到/等待/已出牌、当前暂时最大与上一墩展开均已实现。不新增人类提示入口。
- 每轮私有 `declarationAcknowledged[seat]` 按花色/点数/强度确认，成功亮主或 `pass` 确认本人当前机会；新花色/更强对子/王对会再次暂停，原已跳过机会不循环暂停。跳过不永久放弃亮主，仍可点击当前合法项。每轮重新清空确认；兼容缺少该字段的旧本地存档。
- `GameDefinition.automationBlocked(state, humanSeats)` 为可选钩子，仅拖拉机启用。`Table` 使用**运行时**在线、非机器人、非托管座位，暂停期间清掉全部系统、机器人、人类超时定时器，取消外部异步决策；执行入口也拒绝过期自动动作。其他玩法没有钩子，保留原调度。`humanTimeoutEnabled` 在拖拉机发牌/亮主阶段关闭普通回合超时，避免跳过之后被自动替亮。
- 联机每个仍有新合法机会的真人分别确认，一人跳过不代表其他人确认。不会向其他座位或旁观者发布机会候选、确认令牌或待确认座位名单；view 只包含本人的五项候选及本人 `awaitingDeclaration`。
- **恢复策略**：在线真人不因等待时间被夺取决定权；本人可主动开启托管。断线时仅该席按已有联机策略转电脑并解除该席的暂停约束，其他在线真人仍受保护。重连/取消托管恢复真人身份，若尚有未确认的合法机会会再暂停；已经由电脑做出的公开动作不回滚。旁观者不构成暂停条件。
- 暂时最大直接使用 `currentTrickWinner`，与四家完成时的服务端结算共用原比较器。甩牌、退牌每张10分、强制压、同大先出、默认不限局与过A回2均未改变。
- `npm run check`：30文件261测试；其中13项新运行器用例覆盖系统/电脑竞争、多人逐席确认、最后反主窗口、无超时夺权、跳过后仍可亮、新机会再暂停、隐私、异步结果取消及断线/托管恢复实际发牌。

### 旧 iPad 交互改版（历史阶段，`?check=20261105-3`）

- 仅本地会话将发牌节拍覆盖为 1100ms；共享引擎原来的 320ms/2400ms 系统动作、规则与主站部署不变。
- `LegacyTractorSession.declarations` 固定返回黑桃、红桃、梅花、方块、无主五项，候选只取自己已收到的牌，全部通过共享 `tractor.validate` 验证。每门展示当前最强合法候选，直接确认，不必选牌。
- `awaitingDeclaration` 在每次 `step()` 的任何电脑操作之前检查；新选项暂停发牌和电脑亮主，永不超时替玩家做决定。`skipDeclaration()` 确认当前选项；同门同级同强度不重复暂停，新花色/更强对子/新王对会再次暂停。自己成功亮主确认现有机会并恢复调度；每局清空确认记录。
- `currentTrickWinner(trick, level, trump)` 只读公开出牌，返回暂时最大者座位或 `null`。它直接调用原有 `beats`，完整四张时的引擎结算也改为调用这一相同函数，避免界面另写近似比较器。单张、对子、拖拉机、混合甩、主杀及同大先出不改规则。
- 四方座位：我在下，竹/对家在上，松/下家在右，梅/上家在左。当前墩与上一墩分开；每家的牌独立归属，暂时最大不标成最终胜者。
- 浏览器覆盖 Chromium/WebKit 的 1024×768、1024×660、768×1024 与 844×390；33 张扣底逐张触控及成对几何检测，前三个平板视口完整显示33张。手机可滚动。实际未加速计时验证新机会持续暂停、真人先亮、跳过恢复、后续新机会再次暂停；seed24 两个电脑同时合法可亮时仍不能抢走真人选择。
